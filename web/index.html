Cherry Studio

强烈推荐的桌面多模型客户端

1. 打开 Cherry Studio 设置 → 模型服务 → 添加 OpenAI 兼容格式服务；

2. 填入如下参数：

API 域名: http://localhost:7863
API Key: sk-xxxx
模型名: deepseek-v3 / deepseek-r1

Chatbox

经典轻量跨平台客户端

1. 设置 → 模型提供商选择 OpenAI API；

2. 勾选“自定义 API 域名”，填入网关地址：

API 主机: http://localhost:7863
API Key: sk-xxxx
